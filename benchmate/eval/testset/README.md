# Test set (T2 owns this folder)

Drop photos here from the fixed overhead mount. At least 20 by H+22. Vary: lamp position,
wire placement, both demo failure states (5V on VIN; SDA/SCL swapped), the OK state, and one
with a hand partly in frame.

Naming:

    eval/testset/<n>.jpg          the photo (any integer or short slug, e.g. 01_ok.jpg, 02_5v.jpg)
    eval/testset/<n>.twin.json    ground truth: contracts/twin.schema.json plus two extra keys
                                      "expected_findings": ["supply_voltage"]   # ids from the profile checks
                                      "serial": ["no I2C devices found"]        # serial lines for run_checks
                                      "registrations": [{part_id,row_index,pixel}] # the clicks (label_helper fills them in)
    eval/testset/<n>.overlay.jpg  generated by label_helper.py, never hand-edited (git-ignore-able)

Workflow per photo:

    python eval/label_helper.py eval/testset/<n>.jpg     # drafts <n>.twin.json via build_twin + draws overlay
    # open the overlay, fix holes / part_ids / wires in <n>.twin.json, re-run until it matches
    python eval/run_eval.py --note "what changed"        # appends a row to eval/history.csv
    python eval/plot_history.py                           # eval/accuracy_journey.png

Expected finding ids (from knowledge/profiles/bme280.yaml checks): supply_voltage, ground, i2c_sda, i2c_scl.
OK board -> []. 5V board -> ["supply_voltage"]. Swapped -> ["i2c_sda", "i2c_scl"].
